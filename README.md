# CCL KiCad Libraries
This repository refers to ChipCodeLab's custom-designed symbols, footprints and 3D model library for KiCad EDA.

## How to use KiCad CCL Libraries
* Download latest libraries from [CCL KiCad Libraries](https://gitlab.com/kicad/libraries)
* Add libraries to your KiCad EDA
